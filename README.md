# Memory Game Project

Welcome To My Memory Game Project! This Is A Classic Card Matching Game Built With HTML, CSS, And JavaScript.

## Features:
- 🎮 16 Cards In A 4x4 Grid Layout.
- 🔄 Cards Are Shuffled Randomly Every Time You Start A New Game.
- ⏱️ Live Timer To Track Your Playing Time.
- 🔢 Move Counter To Track The Number Of Attempts.
- 🎉 Win Popup Displaying Your Final Moves And Time.
- 🔒 Matched Cards Get Locked And Cannot Be Flipped Again.
- 🔄 Smooth Flip Animations.
- ✅ Fully Responsive And Works On All Devices.

## How To Play:
1. Click On "Start Game" Button To Begin.
2. Flip Two Cards To Find A Match.
3. Matched Cards Will Stay Open And Locked.
4. If Cards Do Not Match, They Will Flip Back.
5. Win The Game By Matching All 8 Pairs!

## Technologies Used:
- HTML5
- CSS3
- JavaScript (Vanilla)
